# Future annotation evaluation

Do not add drawing, arrows, rulers, or before/after comparison until real UI-review sessions show the current element/region/page targets cannot express a request. Record for each unmet request: target type used, intended reference, whether a screenshot or DOM context would suffice, and how much extra interaction the proposed tool adds.

Candidate order for user testing: responsive viewport presets (low interaction cost), alignment/spacing measurement, before/after comparison, then arrows/freehand and color picker. Test whether each improves agent fix accuracy and reviewer completion time rather than counting annotations created. Keep screenshot redaction and transport reliability ahead of image editing.

No user study has been run; this is a decision framework, not validation or an implementation claim.
